🛒 E-commerce Básico
🚀 Tienda en línea desarrollada con React y Firebase, con autenticación de usuarios y carrito de compras interactivo. Optimizada para rendimiento con lazy loading y prefetching.

🔹 Características
🔑 Autenticación de usuarios con Firebase/Auth0.
🛍️ Carrito de compras interactivo con Redux Toolkit para la gestión de estado.
⚡ Carga optimizada con lazy loading y prefetching, reduciendo el tiempo de carga en un 30%.
🔥 Base de datos en tiempo real con Firebase Firestore.
📦 Gestión de productos y pedidos en una interfaz intuitiva.

📦 Tecnologías Utilizadas
✅ React
✅ Firebase (Auth y Firestore)
✅ Redux Toolkit
✅ React Router
✅ Tailwind CSS
